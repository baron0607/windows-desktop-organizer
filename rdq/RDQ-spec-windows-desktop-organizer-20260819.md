# RDQ 需求規格：Windows桌面整理工具 (WinDeskBox 桌面收納箱)

## 一句話任務
打造 Windows 11 專用免安裝、低佔用之 Fluent 毛玻璃桌面分區收納工具（WinDeskBox），支援任意自訂資料夾映射（Folder Portal）、分頁收納 (Tabs)、開機自動啟動與 100% 離線純淨資安防護。

## ✅ 已確認
- **產品名稱**：**WinDeskBox**（中文簡稱：**桌面收納箱**）（Ⅰ）
- **核心技術**：C# / .NET 8 (LTS) (WPF + Win32 Shell API)，原生編譯為單一免安裝 Portable Self-Contained `.exe`，設定檔為本機 `./config.json`（Ⅰ）
- **自訂資料夾映射**：可新增多個收納盒並分別映射指定路徑（如 `D:\forest\桌面區\執行中`、`常用捷徑`），顯示內部所有子資料夾與檔案（Ⅰ）
- **桌面底層嵌入與視覺**：Windows 11 DWM Acrylic 毛玻璃、圓角、暗黑/淺色、WorkerW 桌面底層鎖定（永不遮擋視窗）、標題列滾動收合（Roll-up）、雙擊桌面空白處一鍵隱藏/顯示（Ⅰ）
- **開機自動啟動**：透過 Windows Startup 個人啟動區捷徑機制實現免安裝無痕開機自啟（Ⅰ）
- **觸發機制**：取消即時背景攔截，採手動一鍵整理與啟動整理（Ⅰ）
- **資安防護**：100% 離線純淨零網路（Zero Telemetry）、目錄授權白名單邊界防護與 Path Traversal 防禦（Ⅰ）
- **檢視排版**：收納盒預設採「大圖示網格」，支援右鍵切換為「簡潔清單列表」（Ⅲ）
- **子資料夾行為**：雙擊子資料夾直接以 Windows 檔案總管開新視窗（Ⅲ）
- **衝突處理**：檔案拖入或整理遇同名時，彈出確認提示對話框由使用者選擇覆蓋/略過/保留兩者（Ⅲ）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 單一收納盒預設寬高 → 預設寬度 320px、高度 260px，使用者可自由拖曳縮放
- 毛玻璃預設不透明度 → 預設背景透明度 70% (0.7) 搭配 Windows 11 Acrylic Blur
- 桌面磁吸吸附距離 → 靠近螢幕邊緣或鄰近收納盒 15px 內自動吸附

## ➕ 已採納（象限Ⅳ）
- **智慧排序**：收納盒支援依修改時間、檔案類型或名稱排序（最新檔案置頂）
- **資源回收筒安全刪除**：收納盒內支援按 Delete 鍵將檔案安全移入 Windows 資源回收筒（`SHFileOperation`）
- **分頁式收納盒 (Tabs)**：支援在單一收納盒內以標籤頁切換多個映射目錄

## ❌ 排除項（明確不做）
- **排除即時檔名搜尋輸入框**：保持收納盒標題列極簡純淨，不額外佔用介面高度
- **排除即時背景目錄監聽自動搬移**：不做未經使用者手動觸發的背景檔案攔截

## 📋 一段式需求規格
為 **Windows 11** 開發免安裝可攜版桌面管理工具（**WinDeskBox 桌面收納箱**），採用 **C# / .NET 8 (LTS) (WPF)** 與 **Win32 Shell API** 打造。軟體提供**自訂資料夾映射收納盒 (Folder Portal)** 功能，使用者可建立多個分區並綁定如 **`D:\forest\桌面區\執行中`**、**`常用捷徑`** 等任意指定目錄，亦支援在單一收納盒以 **分頁 (Tabs)** 管理多目錄。收納盒預設以**大圖示網格**列出該路徑下所有**子資料夾與檔案**（具原生系統圖示），支援切換為清單列表，雙擊檔案以預設程式開啟、雙擊子資料夾以**檔案總管**開啟，並支援按 **Delete** 鍵安全移入資源回收筒。介面採用 Windows 11 **Acrylic 毛玻璃**、**WorkerW 桌面底層鎖定**、**標題列自動收合**與**雙擊桌面隱藏**。軟體支援**隨開機自動啟動**（Startup 捷徑）、手動一鍵整理桌面散亂檔案，並嚴格落實 **100% 離線純淨**、**白名單目錄授權邊界防護**與同名提示對話框。

## ✔ 驗收條件
- [ ] 執行單一 `WinDeskBox.exe` 即刻載入設定檔並在桌面背景層顯示毛玻璃收納盒
- [ ] 成功將 `D:\forest\桌面區\執行中` 與 `常用捷徑` 映射為獨立收納盒，子資料夾與檔案正確顯示且可雙擊啟動
- [ ] 雙擊桌面空白處可即時隱藏/顯示所有收納盒；滑鼠移出標題列自動滾動收合
- [ ] 開啟「開機自動啟動」後，系統重啟登入能自動就緒於桌面且無任何外部網路連線
