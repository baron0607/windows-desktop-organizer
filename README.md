## 🌟 核心特色 (Key Features)

### 1. 📁 自訂資料夾映射收納盒 (Folder Portal)
- 隨心將本機或雲端硬碟中的任意資料夾直接映射為桌面收納盒。
- 即時展示子目錄與檔案清單，支援直接雙擊開啟、右鍵選單與快捷鍵（`Ctrl+C` 複製 / `Ctrl+X` 剪下 / `Ctrl+V` 貼上 / `F2` 命名 / `Delete` 刪除）。
- 外部檔案拖曳存入全面採用 **安全複製（Copy）** 模式（原始檔案完好無損）與同名衝突防呆提示。
- 標題列快捷鍵一鍵在「檔案總管」中開啟對應資料夾。

### 2. 🗂️ 分頁收納系統 (Tabs)
- 單一收納盒內支援建立多個分頁（Tabs），將相關專案或目錄集中管理，大幅節省桌面空間。

### 3. 🛡️ 隱私防護鎖定 (Privacy Shield Lock)
- 遇到同事或訪客經過座位時，點擊標題列右上角的 **🛡️ 盾牌按鈕**，收納盒內容會立即套用高強度毛玻璃模糊並覆蓋解鎖盾牌。
- 需要使用時，在防護畫面上**滑鼠雙擊（點兩下）**即可瞬間解鎖。

### 4. ⌨️ 全域自訂快速鍵 (Global Hotkey)
- 支援在「設定」視窗中自由配置修飾鍵（`Alt` / `Ctrl` / `Shift` / `Win`）與主按鍵（預設 `Alt + D`）。
- 按下快速鍵即可一秒切換所有收納盒之「顯示 / 隱藏」，即時生效並自動同步右下角系統匣選單提示。

### 5. 🔍 JUMBO 256x256 超高畫質圖示 & 原生 ClearType
- 整合 Windows Shell 原生提取技術，呈現點對點像素對齊的無損清晰圖示與微軟正黑體/Segoe UI 銳利文字，無任何軟體陰影模糊。
- 支援一鍵切換「大圖示 (Grid)」與「詳細清單 (List)」檢視模式。

### 6. 🧹 桌面一鍵智慧整理工具 (Auto-Organizer)
- 桌面雜亂時，一鍵將散落在桌面上的 Word、Excel、PDF、照片等檔案安全歸檔至 `_桌面收納箱` 目錄。
- 支援「一鍵還原檔案至桌面」，整理過程安全零風險。

### 7. 🎨 Windows 11 Fluent 現代極簡美學
- **26px 極簡純灰標題列**：左側漢堡選單、置中標題、右側 4 大快捷功能按鈕（📁 開啟資料夾、⊞/☰ 切換排列、🔒/🔓 鎖定位置、🛡️ 隱私防護）與 ⌄ 收合箭頭。
- **純粹透明中性煙燻灰本體**：高質感中性半透明，不隨桌面桌布顏色偏藍變色。
- **8 向全方位邊框縮放**：支援四邊（`↔` / `↕`）與四角（`↖` / `↗`）原生順暢拖曳縮放。
- **自動收合 (Roll-up)**：支援滑鼠移出自動捲起為極窄標題列、移入自動展開。

### 8. 🔒 100% 企業防毒相容與離線資安保證
- 採用 Windows 標準視窗與快速鍵 API，徹底排除敏感跨進程 Hook 與探測行為，經企業級防毒（Trend Micro Apex One）實機驗證完全相容無告警。
- 100% 本地離線運行，絕不上傳任何檔案或隱私數據。

### 9. 🚀 免安裝單一執行檔 (Portable Self-Contained)
- 內建完整 .NET 8 (LTS) 執行環境，無需在電腦額外安裝任何 Runtime。
- 下載單一檔案 `WinDeskBox.exe`（約 161 MB）即可直接隨身攜帶、隨開即用！

## ⚙️ 介面與操作快速指引 (Quick Usage)

### 標題列快捷功能按鈕

```text
[☰ 漢堡選單] ────────── 常用捷徑 ────────── [📁] [⊞/☰] [🔒/🔓] [🛡️] [⌄]
```

- **☰ 漢堡選單**：開啟收納盒設定、重新命名等選項。
- **📁 開啟資料夾**：直接在 Windows 檔案總管中開啟當前映射的目錄。
- **⊞ / ☰ 切換檢視模式**：在大圖示網格與詳細清單檢視之間快速切換。
- **🔒 / 🔓 鎖定位置**：鎖定收納盒位置與尺寸，防止誤觸拖曳與縮放。
- **🛡️ 隱私防護**：一鍵開啟毛玻璃模糊與解鎖盾牌，雙擊畫面解鎖。
- **⌄ 收合 / 展開**：手動摺疊收納盒為極簡標題列。

### 設定面板
- 右鍵點擊系統匣圖示或收納盒漢堡選單中的 **「⚙️ 收納盒與資料夾映射設定...」** 進入設定視窗。
- **開機自動啟動**：隨 Windows 開機自動背景啟動。
- **快速鍵自訂**：可自由配置組合鍵（`Alt` / `Ctrl` / `Shift` / `Win`）＋主按鍵。
- **原地熱更新儲存**：點擊「💾 儲存並套用」時在背景無縫即時生效，不關閉視窗、不搶焦點。
